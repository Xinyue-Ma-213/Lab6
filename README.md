# My Anime Collection

This is a responsive two-page anime recommendation website created for CCT360 Lab 6.

## Featured Anime

- Sword Art Online
- One Piece
- One Punch Man
- The Disastrous Life of Saiki K.
- Fate Series
- AIR

## Website Features

- Responsive Bootstrap 6 navbar and drawer
- Three-slide carousel
- Six anime cards
- Expandable details
- Six interactive dialogs
- Responsive contact form
- Custom purple theme

This is a non-commercial student project.
